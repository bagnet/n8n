## 📦 Файли workflow для імпорту в n8n

### 1. 🔰 **growatt-basic-workflow.json** (базова версія)
**Що містить:**
- ✅ Моніторинг кожні 5 хвилин
- ✅ Статус батареї, напруги, потужності
- ✅ Тривога при низькому заряді (<28%)
- ✅ Українська мова + емодзі

**Для кого:**
- Новачків
- Хочеш простий моніторинг
- Не потрібні кнопки та графіки

**Розмір:** ~3 KB

---

### 2. 🚀 **growatt-ultimate-workflow.json** (розширена версія)
**Що містить:**
- ✅ Все з базової версії
- ✅ **Інлайн-кнопки** для керування
- ✅ **Живі графіки** (24 год / 7 днів)
- ✅ Режим **ВІЙНА** ⚔️ (max ємність)
- ✅ Режим **МИР** 🕊️ (економія циклів)
- ✅ Тривога при повній зарядці (≥94%)
- ✅ Турбо-заряд та нічна зарядка

**Для кого:**
- Досвідчених користувачів
- Хочеш повний контроль
- Потрібні графіки та кнопки

**Розмір:** ~8 KB

**Додатково:**
- Потрібно налаштувати webhook (див. SETUP_GUIDE_UK.md, Крок 5)

---

### 3. 🧪 **test-workflow.json** (тестовий workflow)
**Що робить:**
- Перевіряє підключення до Growatt API
- Тестує логін/пароль
- Отримує Plant ID та Device ID
- Показує поточний статус інвертора
- Надсилає результат в Telegram

**Для кого:**
- Перед активацією основного workflow
- Виникли проблеми з підключенням
- Хочеш перевірити налаштування

**Як використовувати:**
1. Імпортуй в n8n
2. Натисни "Execute Workflow"
3. Через 10-15 секунд отримаєш результат в Telegram

**Розмір:** ~4 KB

## ⚙️ Конфігурація

### **[.env.example](.env.example)** — приклад змінних середовища
**Містить:**
- `SHINEPHONE_LOGIN` — email від ShinePhone
- `SHINEPHONE_PASSWORD` — пароль
- `TELEGRAM_CHAT_ID` — твій Telegram ID
- `TELEGRAM_CREDENTIAL_ID` — ID credential в n8n
- `TELEGRAM_BOT_TOKEN` — токен бота (вже є)

**Як використовувати:**
1. Скопіюй файл: `cp .env.example .env`
2. Відредагуй своїми даними
3. **НЕ ПУБЛІКУЙ .env файл!**

## 🎯 Що імпортувати?

### Сценарій 1: "Новачок, хочу спробувати"
1. Імпортуй **test-workflow.json** → перевір підключення
2. Якщо тест пройшов ✅ → імпортуй **growatt-basic-workflow.json**
3. Активуй workflow

### Сценарій 2: "Хочу всі функції відразу"
1. Імпортуй **test-workflow.json** → перевір підключення
2. Якщо тест пройшов ✅ → імпортуй **growatt-ultimate-workflow.json**
3. Налаштуй webhook (SETUP_GUIDE_UK.md, Крок 5)
4. Активуй workflow

### Сценарій 3: "Маю проблеми"
1. Прочитай **FAQ.md** → Troubleshooting
2. Запусти **test-workflow.json** → подивись помилку
3. Виправ налаштування
4. Повтори тест
