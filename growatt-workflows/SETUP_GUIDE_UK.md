# 🚀 Покрокова інструкція налаштування Growatt бота

## 📋 Що тобі знадобиться (5 хвилин)

- ✅ Доступ до n8n (наприклад: https://n8n.smartvet.space)
- ✅ Логін і пароль від **ShinePhone** (додаток Growatt)
- ✅ Telegram акаунт
- ✅ Токен бота (вже є): `8136712370:AAEdVYxRzzBYoUDuTwC68cW2fNA4rtSCC0c`

---

## Крок 1️⃣: Отримати Telegram Chat ID (30 секунд)

1. Відкрий **Telegram** на телефоні або комп'ютері
2. В пошуку знайди: `@userinfobot`
3. Відкрий діалог з ботом
4. Напиши: `/start`
5. Бот відповість таким повідомленням:

```
👤 User Info

Id: 123456789          ← ЦЕ ТВІЙ CHAT ID, скопіюй це число!
First name: Іван
Username: @ivan_ua
Language: uk
```

6. **Скопіюй число з рядка "Id:"** — це твій `TELEGRAM_CHAT_ID`

> 💡 Збережи це число окремо, воно знадобиться в кроці 3!

---

## Крок 2️⃣: Створити Telegram Credential в n8n (2 хвилини)

1. Відкрий свій **n8n** в браузері
2. Натисни на іконку **⚙️ (Settings)** в лівому меню
3. Вибери **Credentials**
4. Натисни кнопку **+ New**
5. В пошуку знайди: `Telegram`
6. Вибери **Telegram API**
7. Заповни форму:

```
Credential Name: Growatt Bot
Access Token: 8136712370:AAEdVYxRzzBYoUDuTwC68cW2fNA4rtSCC0c
```

8. Натисни **Save**
9. **ВАЖЛИВО:** Після збереження, подивись в URL браузера:
   ```
   https://твій-n8n.com/credentials/1    ← це ID твого credential
   ```
   Або просто подивись в списку credentials — там буде показано ID (зазвичай `1` якщо це перший)

10. **Запиши цей ID** — він знадобиться в наступному кроці!

---

## Крок 3️⃣: Налаштувати змінні середовища (3 хвилини)

1. В n8n перейди в **Settings** → **Variables** (або **Environments**)
2. Додай наступні змінні одну за одною:

### Змінна 1: SHINEPHONE_LOGIN
```
Key: SHINEPHONE_LOGIN
Value: твій_email@gmail.com    ← email від ShinePhone додатку
```

### Змінна 2: SHINEPHONE_PASSWORD
```
Key: SHINEPHONE_PASSWORD
Value: твій_пароль              ← пароль від ShinePhone
```

> 💡 **Примітка про пароль:** 
> - Спочатку спробуй звичайний пароль
> - Якщо не працює — переведи в MD5:
>   1. Відкрий термінал
>   2. Виконай: `echo -n "твій_пароль" | md5sum`
>   3. Скопіюй хеш (без `-` в кінці)

### Змінна 3: TELEGRAM_CHAT_ID
```
Key: TELEGRAM_CHAT_ID
Value: 123456789                ← твій ID з кроку 1
```

### Змінна 4: TELEGRAM_CREDENTIAL_ID
```
Key: TELEGRAM_CREDENTIAL_ID
Value: 1                        ← ID credential з кроку 2
```

3. Натисни **Save** для кожної змінної

---

## Крок 4️⃣: Імпортувати workflow (1 хвилина)

### Вибери версію:

#### 🔰 Базова версія (проста, без кнопок):
1. Скачай файл: `growatt-basic-workflow.json`
2. В n8n натисни **Workflows** (ліве меню)
3. Натисни **+ Add workflow**
4. Натисни **⋮** (три крапки) → **Import from File**
5. Вибери файл `growatt-basic-workflow.json`
6. Натисни **Import**

#### 🚀 Ultimate версія (з кнопками, графіками, режимами):
1. Скачай файл: `growatt-ultimate-workflow.json`
2. В n8n натисни **Workflows** (ліве меню)
3. Натисни **+ Add workflow**
4. Натисни **⋮** (три крапки) → **Import from File**
5. Вибери файл `growatt-ultimate-workflow.json`
6. Натисни **Import**

---

## Крок 5️⃣: Налаштувати Webhook (тільки для Ultimate версії) (2 хвилини)

> ⚠️ **ПРОПУСТИ цей крок, якщо імпортував базову версію!**

Якщо імпортував **Ultimate версію з кнопками**:

1. Відкрий імпортований workflow
2. Знайди вузол **"Webhook (Кнопки)"** (в лівому верхньому куті канвасу)
3. Клікни на вузол → відкриється панель справа
4. Знайди поле **Webhook URL** і скопіюй URL
   
   Він буде виглядати так:
   ```
   https://твій-n8n.com/webhook/growatt-callback
   ```

5. Відкрий **термінал** на своєму комп'ютері (або онлайн: https://replit.com)
6. Виконай команду (підстав свій URL від n8n):

```bash
curl -X POST "https://api.telegram.org/bot8136712370:AAEdVYxRzzBYoUDuTwC68cW2fNA4rtSCC0c/setWebhook" \
-H "Content-Type: application/json" \
-d '{"url": "https://твій-n8n.com/webhook/growatt-callback"}'
```

7. Маєш отримати відповідь:
```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

✅ Готово! Webhook налаштовано!

---

## Крок 6️⃣: Активувати workflow (10 секунд)

1. Відкрий імпортований workflow
2. В правому верхньому куті знайди перемикач **Inactive / Active**
3. Переключи його в положення **Active** ✅
4. Workflow тепер працює!

## 🆘 Якщо щось не працює

### Помилка: "Unauthorized" або "Invalid token"
- Перевір токен в Telegram Credential (крок 2)
- Має бути: `8136712370:AAEdVYxRzzBYoUDuTwC68cW2fNA4rtSCC0c`

### Помилка: "Chat not found"
- Перевір `TELEGRAM_CHAT_ID` (крок 3)
- Має бути **тільки число**, без букв

### Помилка: "Invalid credentials" (Growatt API)
- Перевір `SHINEPHONE_LOGIN` та `SHINEPHONE_PASSWORD`
- Спробуй увійти в ShinePhone додаток з цими даними
- Якщо не працює — переведи пароль в MD5

### Бот не надсилає повідомлення
1. Перевір, що workflow **Active** ✅
2. Подивись **Executions** в n8n — чи є виконання?
3. Якщо виконань немає — перезапусти workflow (Inactive → Active)

### Кнопки не працюють (Ultimate)
- Перевір, що виконав **Крок 5** (налаштування webhook)
- Перевір URL webhook в команді `setWebhook`
