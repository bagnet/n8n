## 🚀 Швидке налаштування (5 хвилин)

### Крок 1: Отримати свій Telegram Chat ID

1. Відкрий Telegram і знайди бота **@userinfobot**
2. Натисни `/start`
3. Скопіюй число з рядка **"Id:"** — це твій `TELEGRAM_CHAT_ID`
   
   Приклад: `123456789`

---

### Крок 2: Створити Telegram Credential в n8n

1. Відкрий свій n8n (наприклад: `https://n8n.smartvet.space`)
2. Перейди в **Settings** → **Credentials** → **New**
3. Вибери тип: **Telegram API**
4. Введи дані:
   ```
   Name: Growatt Bot
   Access Token: 8136712370:AAEdVYxRzzBYoUDuTwC68cW2fNA4rtSCC0c
   ```
5. Натисни **Save**
6. Запам'ятай ID цього credential (буде потрібен далі)

---

### Крок 3: Налаштувати змінні середовища в n8n

Перейди в **Settings** → **Environments** і додай:

| Змінна | Значення | Опис |
|--------|----------|------|
| `SHINEPHONE_LOGIN` | твій_email@gmail.com | Email від ShinePhone |
| `SHINEPHONE_PASSWORD` | твій_пароль | Пароль від ShinePhone (можна MD5) |
| `TELEGRAM_CHAT_ID` | 123456789 | Твій ID з @userinfobot |
| `TELEGRAM_CREDENTIAL_ID` | 1 | ID Telegram credential з кроку 2 |

> 💡 **Примітка:** Якщо в ShinePhone API потрібен MD5 хеш паролю, використай:
> ```bash
> echo -n "твій_пароль" | md5sum
> ```

---

### Крок 4: Імпортувати workflow

#### Варіант A: Базовий workflow

1. В n8n натисни **Workflows** → **Add workflow** → **Import from File**
2. Вибери файл: `growatt-basic-workflow.json`
3. Натисни **Import**

#### Варіант B: Ultimate workflow (з кнопками)

1. В n8n натисни **Workflows** → **Add workflow** → **Import from File**
2. Вибери файл: `growatt-ultimate-workflow.json`
3. Натисни **Import**

---

### Крок 5: Налаштувати Telegram webhook (тільки для Ultimate)

Якщо імпортував **Ultimate версію**:

1. Відкрий workflow
2. Знайди вузол **"Webhook (Кнопки)"**
3. Скопіюй URL webhook (буде виглядати так: `https://твій-n8n.com/webhook/growatt-callback`)
4. Встанови webhook для Telegram бота:
   ```bash
   curl -X POST "https://api.telegram.org/bot8136712370:AAEdVYxRzzBYoUDuTwC68cW2fNA4rtSCC0c/setWebhook" \
   -H "Content-Type: application/json" \
   -d '{"url": "https://твій-n8n.com/webhook/growatt-callback"}'
   ```

---

### Крок 6: Активувати workflow

1. Відкрий workflow в n8n
2. Натисни **Active** (переключи в ON)
3. Через 5 хвилин отримаєш перше повідомлення в Telegram! 🎉

## ⚙️ Додаткові налаштування

### Змінити інтервал оновлення

За замовчуванням — кожні 5 хвилин. Щоб змінити:

1. Відкрий workflow
2. Знайди вузол **"Кожні 5 хв"**
3. Зміни значення `minutesInterval` на потрібне (наприклад, `10` для 10 хвилин)

### Змінити поріг тривоги

За замовчуванням тривога при SOC < 28%. Щоб змінити:

1. Знайди вузол **"SOC <28%?"**
2. Зміни значення `28` на потрібне

### Додати інші інвертори

Workflow автоматично отримує перший інвертор з твого акаунту. Якщо маєш кілька:

1. У вузлі **"Отримати Device ID"** зміни індекс:
   ```
   $json["data"][0]["deviceSn"]  ← перший інвертор
   $json["data"][1]["deviceSn"]  ← другий інвертор
   ```

## 🔧 Troubleshooting (Вирішення проблем)

### Бот не надсилає повідомлення

1. ✅ Перевір змінні середовища (`TELEGRAM_CHAT_ID` має бути числом)
2. ✅ Перевір токен в Telegram Credential
3. ✅ Workflow має бути **Active**
4. ✅ Подивись логи в n8n (Executions)

### Помилка "Invalid token"

- Перевір, що токен скопійовано повністю: `8136712370:AAEdVYxRzzBYoUDuTwC68cW2fNA4rtSCC0c`

### Помилка "Invalid plantId" або "Invalid deviceSn"

- Workflow автоматично отримує ці дані через API
- Якщо не працює — перевір логін/пароль від ShinePhone

### Кнопки не працюють (Ultimate версія)

- Перевір webhook в вузлі **"Webhook (Кнопки)"**
- Встанови webhook для бота (див. Крок 5)

## 📊 Структура workflow

### Базовий workflow:

```
Cron (Кожні 5 хв)
  ↓
Growatt Login (отримання токену)
  ↓
Отримати Plant ID
  ↓
Отримати Device ID
  ↓
Growatt Data (отримання даних інвертора)
  ↓
  ├─→ Telegram Статус (відправка повідомлення)
  └─→ SOC <28%? (перевірка заряду)
        └─→ Тривога (повідомлення про низький заряд)
```

Додатково включає:
- **Webhook** для обробки кнопок

## 🎨 Кастомізація повідомлень

### Змінити текст повідомлення

Відкрий вузол **"Telegram Статус"** та відредагуй поле `text`:

```javascript
*Growatt Дім* ⚡️🇺🇦

🔋 Батарея: *{{$json["data"]["batteryPercent"]}}%*
⚡️ Потужність: {{Math.abs($json["data"]["pCharge"]/1000).toFixed(2)}} кВт
☀️ Сонце: {{($json["data"]["ppv"]/1000).toFixed(1)}} кВт
```

### Додати нові кнопки (Ultimate)

У вузлі **"Telegram + Кнопки"** додай новий рядок в `inlineKeyboard`:

```json
{
  "row": {
    "buttons": [
      {
        "text": "🆕 Нова кнопка",
        "additionalFields": {
          "callbackData": "new_action"
        }
      }
    ]
  }
}
```

Потім створи обробник для `new_action` як окремий вузол.
